Prima configurazione

Collega il sito

Si fa una volta sola. Il pannello pubblica le modifiche direttamente su GitHub, dove sta il sito: serve una chiave di accesso GitHub (token), che verrà salvata cifrata con il nome utente e la password che scegli qui sotto.

  1. Apri github.com → Fine-grained token
  2. Nome a piacere, scadenza la più lunga possibile
  3. Repository access: "Only select repositories" → il repository del sito
  4. Permissions → Contents: "Read and write" — poi "Generate token" e copialo

Almeno 10 caratteri. Meglio una frase lunga, es. LunaSulMare-Viareggio26.
